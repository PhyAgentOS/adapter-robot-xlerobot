# FTServo Python SDK source

This directory contains an unmodified vendored copy of `scservo_sdk` from
[`ftservo/FTServo_Python`](https://github.com/ftservo/FTServo_Python), commit
`a203373036723e0d98c6c49b67cf09a9ee299220`.

The upstream project is licensed under MIT.  Its complete license text is
preserved in [scservo_sdk/LICENSE](scservo_sdk/LICENSE).

Only the SDK package is distributed here; upstream examples are deliberately
not included because some write extreme position values.
